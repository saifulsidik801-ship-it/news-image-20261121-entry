Sum up 21 November's world news in one image: a newspaper front page for Saturday 21 November 2026. Lead story: Russian missiles hit Poland, called a deliberate provocation by Warsaw and a grave violation of its airspace by NATO. Also inside: Wall Street slumps into correction, an aid plea for flooded Gaza, France's fourth weekend of cost-of-living marches, COP31's final stretch, Cyclone Akvan, Israel's new government mandate, the Everest helicopter collision, a pancreatic-cancer pill breakthrough, Nigeria's new police law, the next James Bond, and the UK–EU landmark deals.

The program draws the whole page itself with pure Python 3.13 standard library: an embedded 5×7 bitmap font, vector icons, and a small PNG encoder. No network, no fonts on disk — two runs write byte-identical files.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
